# Glossary — terms used across this repo

One table, plain language. Indonesian (Shopee dashboard) terms first where they exist.

| Term | What it actually means |
|---|---|
| **Klik** | Clicks on your affiliate links. The volume lever — everything else derives from this. |
| **Pesanan** | Orders attributed to your links (includes not-yet-completed/unvalidated ones). |
| **Produk Terjual** | Count of commissioned products sold. |
| **Pesanan (Rp)** | Total order value (GMV) attributed to you. **Not your money.** |
| **Komisi Kotor (Rp)** | Gross *estimated* commission before validation. Estimates, not cash. |
| **Komisi (approved)** | Your money: commission on completed + validated orders only. Pending is not yours yet. |
| **EPC** | Earnings Per Click = commission ÷ clicks, per tag. The single number behind START/CONTINUE/STOP. |
| **Pesanan Langsung** | Direct order: buyer checks out the exact product you linked. Pays the **full** set rate. |
| **Pesanan Tidak Langsung** | Indirect order: buyer clicks your link, then buys something else via Shopee's recommendations. Pays **half** the set rate. |
| **Cookie / 7-day window** | Anyone who clicks your link and orders *anything* within 7 calendar days counts as your transaction. |
| **Tag** | Your private label on a link (e.g. `th_a1_t008_txt`). Only you ever read it; buyers never see it. One post = one tag. |
| **Pakai Tag: Ya/Tidak** | The toggle in Shopee's link tool. Always **Ya** — Tidak makes the clicks unattributable. |
| **KomisiXTRA** | Above-base commission set by sellers/brands. *Produk* = open to all affiliates; *Khusus* = targeted, must beat the product rate. Prioritize XTRA products when picking links. |
| **PPh 21/26** | Income tax Shopee withholds from commission. KTP/NPWP must be on file or payout stalls. |
| **Laporan Performa** | Affiliate dashboard report: Klik, Pesanan, Produk Terjual, Pesanan (Rp), Komisi Kotor (Rp). Refreshes daily 16:30 WIB. No official CSV export — copy numbers manually. |
| **Laporan Klik** | Per-custom-link click report, split by tag. Where you verify tags exist. |
| **Warm-up** | First 7 days of a new social account: value posts + replies, zero links. Skipping it gets reach throttled. |
| **Hit / winner** | A post doing >3x your median views. Only winners get cloned (P3) and repurposed (P4). |
| **Template / format** | Template = the abstract shape (hook + structure + emotion), e.g. `list3`. Format = the medium: `txt` / `car` / `vid`. P3 clones templates; P4 changes formats. |
| **First comment** | Your own reply under your post, posted 15–60 min after publishing, holding the ONE tagged link. Never in the post body. |
| **Check-in** | The 25-min, 2x/week ritual: queue health → first-comment links → replies → numbers. See plan Appendix B. |
| **START / CONTINUE / STOP** | Monthly verdicts per platform×format×template: double down / hold volume / pause 30 days. See [monthly-review-example](monthly-review-example.md). |
| **Buffer queue** | Scheduled-but-unpublished posts. Rule: never drop below 2 days deep. |
| **Start Page** | Buffer's free link-in-bio page (counts as one of your 3 free channels). |
| **Pivot** | The monthly Sheet view grouping by platform × format × template → clicks, orders, commission, EPC. |
| **Volume trap** | High views, ~0 commission. Keep the format for reach but swap the linked product category once before killing it. |
